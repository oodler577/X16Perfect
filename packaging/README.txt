X16Perfect for Commander X16

1. Download and extract X16Emu R49 for Windows separately.
   https://github.com/X16Community/x16-emulator/releases/tag/r49
2. Extract this ZIP into its own folder directly inside the emulator directory.
   The parent directory should contain x16emu.exe and its matching rom.bin.
3. Double-click RUN-WINDOWS.bat beside X16PERF.PRG.

Documents are saved in the folder beside X16PERF.PRG.
F5 then Enter lists files. Highlight one and press 1 to retrieve it.
Shift+F10 retrieves directly by filename.
F10 saves. If the name already exists, press Y to replace it or Enter to keep it.

Demo files:
- FORMAT.WPD shows bold, underline, and a hard page break.
  Alt+F3 or F11 opens the inline Reveal Codes view.
- WELCOME.TXT shows ASCII import. Use F10 with a new .WPD name
  to keep the original text file, since F10 saves in WordPerfect format.
