# WordPerfect 5.1 Plus reference

The reference is the English DOS release whose Program 1 disk is dated March 21, 1994. It was installed separately and exercised in DOSBox 0.74-3. The native tests use X16Emu R49. See [COVERAGE.md](COVERAGE.md) for verified X16 behavior.

## DOS pull-down menu inventory

Alt+= opens the menu bar in the reference editor. The table records the first level reached in the running editor. Entries vary with context, including whether a block is active. Submenus and alternate keyboard paths still need enumeration.

| Menu | First-level commands observed |
| --- | --- |
| File | Retrieve, Save, Text In, Text Out, Password, List Files, Summary, Print, Setup, Go to DOS, Exit |
| Edit | Move (Cut), Copy, Paste, Append, Delete, Undelete, Block, Select, Comment, Convert Case, Protect Block, Switch Document, Window, Reveal Codes |
| Search | Forward, Backward, Next, Previous, Replace, Extended, Go to |
| Layout | Line, Page, Document, Other, Columns, Tables, Math, Footnote, Endnote, Justify, Align, Styles |
| Mark | Index, Table of Contents, List, Cross-Reference, Table of Authorities, Define, Generate, Master Documents, Subdocument, Document Compare |
| Tools | Spell, Thesaurus, Macro, Date Text, Date Code, Date Format, Outline, Paragraph Number, Define, Merge Codes, Merge, Sort, Line Draw |
| Font | Base Font, Normal, Appearance, Superscript, Subscript, Fine, Small, Large, Very Large, Extra Large, Print Color, Characters |
| Graphics | Figure, Table Box, Text Box, User Box, Equation, Line |
| Help | Help, Index, Template, WP Info |

The Search menu shows forward on F2, backward on Shift+F2 and replace on Alt+F2. X16Perfect currently binds Shift+F2 to its single replacement workflow. The DOS Print menu shows Full Document, Page, Document on Disk, Control Printer, Multiple Pages, View Document, and Initialize Printer, followed by Select Printer, Binding Offset, Number of Copies, Multiple Copies Generated by, Graphics Quality, and Text Quality. X16Perfect's Print and Printer Setup choices are intentional no-ops. The submenu, confirmation and cancellation inventory remains incomplete.

The running File → Text Out submenu offers DOS Text, Generic, WP5.0, WP4.2 and WP6.0. DOS Text, Generic, WP5.0 and WP4.2 are export paths to verify separately. WP6.0 is outside the release scope.

## File compatibility release gate

Verify the in-scope document formats through the original open, edit, and save workflows. WordPerfect 4.2 import and export are included. WordPerfect 6.x is outside the release scope. Exercise both in-place editing and saving under another name. For conversion workflows, compare the output format and formatting changes made by the original, and reopen the output in DOS. Test plain text export separately from F10, which saves a native document. Include native options for formatting, security, and metadata within each format, plus cancellation, bad inputs and failed writes.

| File or workflow | DOS reference evidence | Native status |
| --- | --- | --- |
| Basic ASCII | Retrieved a two-line CRLF sample into blank and nonempty documents | Editable. F10 saves a WP5 document. Text Out and DOS extended characters remain open. |
| WordPerfect 4.2 | Opened `wp42.wp`, added a character, and saved with F10 in native WP5.1 format after replacement confirmation. File → Text Out → WP4.2 also exported a 4.2 file. The import displays conversion annotations for legacy font and pitch. | Import and explicit 4.2 export are release blockers. |
| WordPerfect 5.0 | Opened `wp50.wp` and displayed its text | The public sample opens read-only. Editing and fidelity are unverified. |
| WordPerfect 5.1 and 5.1 Plus | Opened `wp51.wp`; also opened and re-saved the local formatted round-trip fixture | Editable subset verified in both directions. The public sample has an 8,324-byte prefix and opens read-only. Full record editing and template, merge and password cases remain open. |
| Other shipped converters | The 5.1 reference documents DCA/RFT, DCA/FFT, Navy DIF, WordStar 3.3, MultiMate Advantage II, seven-bit transfer, merge/DIF, Microsoft Word 4.0 and DisplayWrite. Conversion directions vary. | Inventory the exact shipped directions and obtain a test fixture for each. These conversions are not implemented. |
| Ancillary files | WPG, macros, styles and other resources have their own workflows. | Obtain and classify fixtures by command and file type. |

The public WordPerfect samples came from the [xberg-io test corpus](https://github.com/xberg-io/test_documents/tree/main/wordperfect). Its provenance identifies the upstream LibreOffice, Apache Tika and OPF corpus files. The files stay in the test workspace, outside the release archive.
